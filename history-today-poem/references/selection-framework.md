# 选题框架 · 历史上的今天 · 一首古诗

这套规则管的是「今天挑哪件事」，不是「怎么写」。文字要求见 `writing-rules.md`，执行顺序见 `workflow.md`。

优先顺序固定：**真实性 > 读者新鲜度 > 可读性 > 配额**。配额是排期工具，不是硬指标；为了凑比例降低真实性或硬选不新鲜的题，是本末倒置。

## 一、四道硬门槛，一票否决

放在查资料之前，不是写完再检查。任何一条不过，直接换题。

1. **日期确凿**。事件有完整年月日，且换算成公历后的月日 = 目标发布日 TARGET 的月日。农历记载要换算并复核，算不准就换题。脚本有硬校验，凑不出来会报错。
2. **来源够**。至少 2~3 个独立来源，年份、人物、地点、过程、数字对得上。只有一条来源、只有「据说」、只有百科聚合页的，不选。
3. **安全**。不碰政治敏感、定性有争议、主权表述有争议、宗教冲突、近期恐袭与大屠杀。中国近现代史**只避政治性题材**，不是整段绕开——见第五节口径说明。
4. **配得上诗**。事件的情绪能被某首古诗接住。纯条文、纯战绩、纯数据发布，或惨烈到配任何古诗都显得轻佻的，不选。

四条都过，才进入下面的配额、轮换和打分。

### 附加硬门槛：单纯「生卒类」事件一票否决（用户明确要求）

「某年某月某日，某某出生／逝世」这类事件**直接否决，不进入候选**，如「朱自清出生」「钱钟书出生」。理由：人物本身有名气，但「出生」这件事没有过程、没有具体故事，对历史没有直接影响，读者关注度为零，写出来只能靠生平罗列充字数。

- 人物生卒只有在**绑定具体可讲的事件**时才可选：如「中国第一座自建铁路通车」「某所大学举行第一堂课」「某报创刊」——主体是事件，不是生卒。
- 仅当生卒本身有标志性意义（如开国级人物的生卒、历史上第一个某种身份的人）且能展开出具体经过时，才例外，并要在打分里如实体现（这类题 freshness 一般只能拿 0~1 分）。
- **重大贡献人物的诞辰/逝世周年例外（用户 2026-11 明确要求）**：对人类或对国家有特别贡献的人物（科学家、医学家、工程师、文学家等），其诞辰/忌日整周年（100 周年这类整数节点优先）可以入选，不再按「生卒类」一票否决。写法要求：正文围绕**具体贡献与具体故事**（发现了什么、建成了什么、改变了什么），不写生平罗列；`event.date` 填生/卒完整年月日；标题用大众熟知的称号 + 周年表述（如「李政道诞辰 100 周年」）；生卒日期需 2~3 源核实。
- 同理否决的还有：纪念日流水账、「某某就任某职」这类没有具体故事的名录式条目。

## 二、选题偏向：中国为主，挑有意义的小事件

**每天 3 篇。优先中国相关的事件，每周约 15 篇中国 + 6 篇国际（保持 5:2 比例）。**

两个偏向同时成立才有意思：

1. **中国为主**。栏目给读者一个自己的时间坐标。整周都是外国人名地名，读者没有落点。
2. **小人物的、不被大众关注的事件**。不要年年被转发的大事，也不要课本里讲烂的题；要具体的人、具体的动作、具体的一天。例如一条铁路通车、一次试飞、一本书的初版、一次考古发掘、一所大学的第一堂课——有意义，但多半没人记得那天是哪天。
3. **不是冷知识**。小事件也要能撑起 200 字上下的经过（见第四节打分 `depth`），并且读完能留下一个具体的画面，而不是「某年某月发生过某事」。
4. **国际 2 篇留出口子**。科技、工程、医学、探险、天文、考古这些池子里，国外日期确凿、公开来源多、争议少，也容易留白，正好适合「只讲诗、不解释连接」的写法。国内某周凑不出 5 个合格题，就拿国际补，下周再调回来——**配额是排期工具，绝不为了凑数降低真实性门槛**。

配额靠台账算，不靠回忆。每次开跑先执行：

```
python history_post.py --quota
```

输出里 `week`、`region`、`pool`、`mood`、`recent_devices`、`recent_events`、`recent_poems`、`advice` 直接用。台账见第六节。

## 三、读者新鲜度

优先选**读者多半不知道、但确实有据**的事：冷门工程、一次首航、一本书的出版、一个标准怎么定下来的、一个人出发的那天。

- 年年被转发的「大事件」、中小学课本里讲烂的事，除非有具体的新角度且有据，否则不选。
- 标题一看就知道结局、正文只能复述常识的，不选。
- 新鲜度是打分的第一项，占 0~2 分；这一项拿 0 分的题，基本不可能过 6 分门槛。

## 四、题材池与气质轮换（比配比更管用）

### 6 个题材池

| 池 | 装什么 |
| --- | --- |
| 造物 | 工程、发明、通车、开通 |
| 发现 | 天文、地理、考古、医学 |
| 纸上 | 书籍、报刊、乐谱、影片首演 |
| 制度里的一小步 | 标准、计量、邮政、计时、地图 |
| 人的一天 | 一次出发、一封信、一个具体决定 |
| 旧物与遗迹 | 建筑落成、器物重见、遗址 |

### 5 种气质

轻快 / 沉静 / 荒凉 / 意外 / 敬佩。

### 轮换规则

1. **相邻两天不重池、不重气质、不重笔法、不重诗**；同一首诗、同一件事最近 14 天写过就不再用。
2. 每周每池最多 3 篇（一天 3 篇后总量变大），气质尽量铺开；不要连着三天「沉重写灾难」，也不要连着三天「庆功式突破」。
3. 别连着几天都选战争、灾难、签条约这类同气质题材。
4. 行文笔法从 `writing-rules.md` 的 8 种里换，`--quota` 会列出最近 5 篇用过的。

## 五、安全池与避开清单

### 国内可写

- 古代与近代的科技工程、水利桥梁、天文观测与历法、农书医书成书刊刻、考古发现、古籍著录、书画戏曲首演（有确切日期）。**人物生卒类见附加硬门槛：单纯出生/逝世一律否决。**
- 有公文档案的报刊创刊、第一条铁路 / 电报 / 航线、大学开学、博物馆开放、科考队出发或归来。
- **中国近现代非政治性题材正常选**：铁路通车、电报开通、大学与医院开办、报刊创刊、考古发掘、工程落成、科学观测、人物生卒。这类日期确凿、档案公开、争议少，是好题来源。

### 国内避开

战争胜负、政治运动、政权更迭、条约签订、涉主权表述、定性有争议的纪念日，以及一切政治敏感内容。

### 国外可写

通车首航首飞、探测器与天文发现、医学与公共卫生、书籍报刊与影片首演、探险与地理发现、标准计量专利这类技术性制度、日常生活里的小转折。

### 国外避开

政权更迭、军事政变、恐袭、大屠杀、宗教教义争议。

> **口径说明（为什么把「中国近现代政治史一律绕开」改成「只避政治性题材」）**：原来的写法一刀切太宽，把铁路、报刊、大学、考古这些日期确凿的好题一起排除了。真正要避的是**政治性**：这类事件的日期、定性、因果在不同来源里常对不上，平台审核也更严，日更栏目经不起一次事故；而且配古诗时容易被读成影射，与本栏目「不解释诗与事件连接」的留白写法相冲。非政治性的近现代史没有这些问题，照常选。

## 六、5 项打分，低于 6 分换题

四道门槛全过 → 看本周配额缺口 → 看池子与气质空位 → 剩下的候选逐项打分，每项 0~2 分：

| key | 看什么 | 2 分的标准 |
| --- | --- | --- |
| `freshness` | 读者新鲜度 | 多数读者不知道，且不是纯冷知识 |
| `depth` | 可展开 | 有足够可核实的事实撑得起 200 字上下的经过，不是一句「发生了某事」就没了 |
| `scene` | 画面 | 至少一处能看见的细节或具体的人 |
| `poem_fit` | 配诗空间 | 能找到情绪相通、原文可核的古诗 |
| `sources` | 来源质量 | 有官方或一手来源，2~3 源能对上 |

- **合计低于 6 分就换题，宁可今天不出稿。** 脚本 `validate()` 会挡下 `selection.score < 6` 的稿，不要改校验绕过。
- 同分时优先补配额缺口（尤其是中国稿），其次优先冷门。
- 分数写进 `selection.score`，明细可写进 `selection.scores`（五项各 0~2，脚本会核合计是否一致）。
- 打分是写稿时自己给的判断，不是史实；台账留着是为了复盘，不是为了凑分。

## 七、标题要落到大众熟知的符号上

同一件事有两种写法时，永远选读者一眼认得出的那个符号：

- 写「米老鼠第一次亮相」，不写「《威利号汽船》首映」。
- 写「第一封电子邮件发出」，不写「ARPANET 节点间传输实验」。
- 写「北京地铁第一条线通车」，不写「北京地下铁道一期工程验收交付」。

两条底线：符号必须**准确**对得上这件事实（米老鼠确实是在《威利号汽船》里首次亮相，这类前提要核实）；实在没有通俗说法，就用平实的一句话把事说清，不要硬造一个流行词。标题里不出现事件发生日期——日期由脚本统一放在正文顶部那行。

## 八、台账与落盘标签

每篇 JSON **必填** `selection` 块，字段不进排版，只供台账统计：

```json
"selection": {
  "region": "国内",
  "pool": "造物",
  "mood": "轻快",
  "device": "从最不起眼的一步写起",
  "score": 9,
  "scores": {"freshness": 2, "depth": 2, "scene": 2, "poem_fit": 2, "sources": 1}
}
```

- `python history_post.py --quota` 读 `data/selection-log.json`，并补充 `data/history/20??-??-??.json` 里尚未投递的稿，算出最近 14 天和本周的配额、池子、气质、笔法与黑名单。
- 正式投递成功后，脚本按发布日写入台账（一天一行）；`--dry-run` 不写，避免自测污染配额。
- 台账不存在或读不到时如实说明，不要凭记忆编一份清单。

## 九、决策顺序（每次照这个走）

1. 确认 TARGET（北京时间的明天）→ `python history_post.py --quota`；读避重清单（最近写过的事件与诗）。
2. 搜「历史上的 X月X日」，列 **6~10 个候选**（每天要做 3 篇，候选要够量），优先中国题 → 过四道硬门槛 + 生卒类否决。
3. 看本周配额缺口、池子与气质空位，删掉会撞车的候选（最近 14 天写过的事件、诗一律排除）。
4. 剩下的按 5 项打分；低于 6 分的换掉。
5. 取最高分（同分优先补中国稿缺口、优先冷门）→ 联网核实完整日期与全部事实 → 写作与配诗 → 落盘 `<TARGET>.json`。
6. 投递成功后台账自动更新，下一轮从台账接着算。

## 十、一周排期示意

每天 1 篇，一周 5 篇中国、2 篇国际。池子、气质、笔法隔天错开。事件列需联网核实后填；只有第 1 天是已核实的样例，其余不是正式稿。

| 天 | 地区 | 题材池 | 气质 | 事件 |
| --- | --- | --- | --- | --- |
| 1 | 国内 | 造物 | 意外 | 1851-11-13 类型：一条电缆 / 一段铁路开通（样例，需按当天月日核实） |
| 2 | 国内 | 纸上 | 沉静 | 待核实，优先创办 / 初版 / 首演 |
| 3 | 国际 | 发现 | 意外 | 待核实，天文、考古、医学 |
| 4 | 国内 | 人的一天 | 敬佩 | 待核实，一个普通人的具体决定 |
| 5 | 国内 | 制度里的一小步 | 沉静 | 待核实，标准、计量、邮政、计时 |
| 6 | 国际 | 旧物与遗迹 | 荒凉 | 待核实 |
| 7 | 国内 | 发现 | 轻快 | 待核实，按配额缺口定 |

排期只是示意：真实选题以当天「历史上的 X月X日」有什么为依据，凑不出合格的就不出，别为对齐这张表硬选。
