# history-today-poem skill

公众号「历史上的今天 · 一首古诗」的运营 skill 包（Hermes Agent skill）。

- `SKILL.md`：skill 主文件（链路口径、铁律、命令速查、数据格式）
- `references/selection-framework.md`：选题框架（四门槛、配额、打分、台账）
- `references/writing-rules.md`：写作规则
- `references/workflow.md`：完整 SOP 与踩坑记录
- `references/cover-design.md`：封面风格库与设计迭代规则

每天 17:30（北京时间）自动产出次日 3 篇「历史事件 × 古诗」公众号草稿，人工审核后发布。
